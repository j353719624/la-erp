# 后端服务

Go 编写的自包含 ERP 服务：SQLite 单文件存储、元数据驱动路由、业务写入与会计过账在同一事务中完成。

## 本地运行

需要 Go 1.21+（开发环境用 1.27 验证过）。

```sh
cd backend
go mod download
go test ./...
go build -o la-erp-server ./cmd/la-erp-server
./la-erp-server -dev -listen 127.0.0.1:18887 -db data/dev.db
```

Windows：

```powershell
go build -o la-erp-server.exe ./cmd/la-erp-server
.\la-erp-server.exe -dev -listen 127.0.0.1:18887 -db data/dev.db
```

`-dev` 为开发模式：只监听回环地址并跳过授权检查。**生产模式不支持 Windows**，
且默认强制校验授权文件，缺少 `license.key` 会直接启动失败。

空库首次启动会建 162 张表并导入演示基础资料，创建管理员 `admin`（初始口令 `admin123`，
可用 `ERP_ADMIN_PASSWORD` 覆盖）。已有用户时不再导入演示数据。JWT 密钥首次随机生成，
保存在数据库旁的 `.jwt.secret`，重启后复用。

正式启动：

```sh
./la-erp-server -c config.yaml -public-key /secure/public.key -license /data/license.key
```

仓库根目录可跑真实进程冒烟：`node tests/server-smoke.mjs backend/la-erp-server`
（Windows 把路径改 `backend/la-erp-server.exe`）。

前端开发代理指向本服务：

```powershell
cd ..\frontend
$env:ERP_BACKEND_URL = 'http://127.0.0.1:18887'
npm run dev
```

## 模块

| 模块 | 行为 |
| --- | --- |
| 数据库 | 162 张 SQLite 表（含索引与外键），162 个对应 Go 模型 |
| 登录与会话 | bcrypt、HS256 JWT、刷新令牌单次使用、登出、密码修改/重置、令牌版本失效 |
| 组织与权限 | 用户、角色、权限分配、部门、分类树；父子循环检查；本人/部门数据范围 |
| 基础资料 | 商品、客户、供应商、单位、仓库、分类、部门、用户、角色、库区、货架 CRUD |
| 业务读取 | 统一分页列表 + 应收/应付数组读取；部分读取接口限超级管理员 |
| 入出库 | 采购入库、销售出库建单/详情/编辑/删除/确认；加权平均成本、库存不足回滚、库存流水 |
| 库存锁定 | 锁定/释放，可用量与锁定量分别维护 |
| 销售订单 | 明细金额折扣、编辑/删除、数量价格税额计算、确认锁库存、取消释放库存；关联出库消耗锁定库存、回写已交付数量并自动关闭完成订单 |
| 采购订单 | 建单/详情/编辑/删除/确认/取消；确认不产生实际库存；关联入库回写已收数量、拒绝超收 |
| 退货 | 销售/采购退货建单、确认、审批；审批回冲库存与会计凭证，保留来源订单字段 |
| 应收应付 | 手工建单、详情、备注更新、开票信息、未核销删除；AR 建单自动确认收入，AP 不自动过账 |
| 收付款 | 草稿、数组列表、详情、确认核销、草稿取消、已确认取消冲销；超额核销回滚；RFC3339 日期 |
| 自动过账 | 出入库、退货、AR 建单、收付款与取消：分录、posted 凭证、分录关联、月度科目余额在同一事务写入 |
| 手工凭证 | general 草稿创建/替换编辑、过账、审批、取消及草稿删除；cancel 仅改状态，不冲销分录 |
| BOM/工单 | BOM 成本树、工单材料需求、确认/审批/完工及草稿删除；支持多版本、循环与深层嵌套 |
| 生产库存 | 领料/退料/部分或全部成品入库；材料成本、数量上限、草稿删除；事务失败回滚 |
| 生产资料 | 工作中心、工艺路线及工序明细；工单工序开工/报工/撤销、人工成本重算、工序统计 |
| 计划 | MRP 需求计算与采购建议、MPS 主生产计划、批量生成工单、工作中心产能负荷 |
| 仓间调拨 | 草稿/发运/在途/完成/取消；来源均价成本、两仓事务与流水 |
| 调整和盘点 | 盘盈/盘亏/成本调整、盘点启动账面量、实盘差异与流水 |
| 报表 | 销售采购汇总/趋势/利润/价格、库存余额/ABC、试算平衡/利润表/资产负债表/总账/现金流、客户与供应商对账、补货建议，共 19 个接口 |
| 上传 | `POST /api/v1/upload/image`，支持 jpg/jpeg/png/gif/webp/bmp，UUID 文件名，默认 10MB，存放 `uploads/images/` |
| 授权 | 机器码绑定 + 签名校验；启动与请求时检查到期；生产需要有效授权文件 |

业务写入暂限超级管理员。

## 目录

- `cmd/la-erp-server`：服务入口，读取 YAML 配置的 server/database/jwt/license 段
- `cmd/license-verify`：授权校验命令行
- `internal/database`：表结构、初始化数据、参数化 SQL 与事务执行器
- `internal/model`：与数据库字段一一对应的模型
- `internal/auth`、`internal/api`、`internal/business`：会话、接口与事务逻辑
- `internal/business/posting.go`：自动过账与凭证生成
- `license`：授权签名与机器码校验

## 业务规则要点

- **单据编号**：`STIN/STOUT/SO/PO/SR/PRN/AR/AP/RC/PY/VOU/TR/ADJ/IC + 上海日期 + 四位流水号`，
  流水号与单据写入在同一事务
- **日期**：财务与生产接口要求 RFC3339，裸 `YYYY-MM-DD` 返回 400；收付款没有 PUT 路由
- **PUT 语义**：订单类 PUT 替换全部明细，未传 `lines` 会清空明细与金额；
  入出库单只改备注时保留明细。已确认单据拒绝普通编辑与删除
- **成本**：加权平均成本保留 6 位小数，以**可用库存**为加权基础（排除锁定库存）；
  这与以全部在手数量为基础的算法不同
- **生产成本**：领退料使用输入成本（含 0）；成品入库输入成本为 0 时回退为
  `工单总成本 ÷ 工单数量`。已确认退料禁止取消/删除
- **软删除**：科目、币种、银行账户等主数据删除为软删除，保留 UUID 并把编码追加
  `~del~` 与 UUID 前八位，编码不可立即复用
- **上传**：`upload.path` 与 `upload.max_size`（单位 MB，默认 10）可配置；
  已生成的图片 URL 可匿名访问，删除照片记录不会删除文件

## 当前边界

以下分支尚未实现，接口会返回明确的 `501` 而不是假装可用：

- 多公司/多租户隔离、客户门户、自定义审批流
- PostgreSQL 后端（当前只支持 SQLite）
- 多币种收付款与汇兑损益、费用报销与工资折旧的完整过账
- 批次/序列号在多场景下的联动、多仓成本选择、部分高级库存参数
- 未完成的报表与匹配分支（多张同金额候选流水、外币勾对等）

## 测试

`go test ./...` 自带临时数据库，不需要外部服务。部分深度回归用例依赖运行快照
（`evidence/`），该目录不随仓库分发；快照缺失时这些用例自动跳过，干净检出仍然全绿。
